### Summary
Add a welcome banner and current date display to the main homepage (`index.html`).

### Problem Statement
Currently, the landing page feels static and does not greet visitors or display the current date. Adding a clean, responsive welcome message will improve the initial user experience.

### Requirements
- [ ] Add a `<header>` section at the top of `index.html`.
- [ ] Include an `<h1>` heading that says: `Welcome to Our Project!`
- [ ] Add a `<p>` tag with an ID of `current-date` below the heading.
- [ ] Use a small JavaScript snippet to populate `#current-date` with today's formatted date (e.g., `November 14, 2026`).
- [ ] Ensure the banner text is center-aligned using basic CSS.

### Acceptance Criteria
- Opening `index.html` in a browser displays the welcome title and the accurate current date without console errors.
- Changes are clean, well-formatted, and tested on both desktop and mobile viewport sizes.
